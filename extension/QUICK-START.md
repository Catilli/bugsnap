# BugSnap Extension - Quick Start Guide

## ⚡ Install in 3 Steps

### Step 1: Open Chrome Extensions
1. Open Chrome browser
2. Type `chrome://extensions/` in the address bar
3. Press Enter

### Step 2: Enable Developer Mode
1. Look for "Developer mode" toggle (top-right corner)
2. Click to turn it ON

### Step 3: Load Extension
1. Click "Load unpacked" button
2. Navigate to the `bugsnap/extension` folder
3. Click "Select Folder"
4. Done! 🎉

## 🎯 First Use

### 1. Login
- Click the BugSnap icon in your toolbar
- Enter your email and password
- Click "Login"

### 2. Select Project
- Choose a project from the dropdown
- Click "Start Annotating"

### 3. Create Task
- Click any element on the webpage
- Fill in task details
- Click "Create Task"
- Task appears in your BugSnap dashboard!

## ⌨️ Keyboard Shortcut

Press `Alt + B` to quickly toggle annotation mode on/off.

## 🔍 Troubleshooting

**Icon not showing?** 
→ Click the puzzle piece icon, find BugSnap, click the pin

**Can't login?**
→ Make sure your API server is running at `http://localhost:3001`

**Can't annotate?**
→ Make sure you're logged in and have selected a project
